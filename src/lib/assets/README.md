Geist Regular, Medium, and Bold are from the official [Geist font repository](https://github.com/vercel/geist-font/tree/main/fonts/Geist/ttf).

The font files are distributed under the SIL Open Font License in `LICENSE.txt`.
They are embedded in the server bundle for social preview generation, so `/og`
does not depend on fetching a font from an external service at request time.
